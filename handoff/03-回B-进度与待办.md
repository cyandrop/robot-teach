## 五、参数能改的和不能碰的

**能改**：`config.py` 里的 `HSV_RANGES`（颜色阈值）、`MIN_CONTOUR_AREA`（识别灵敏度）

**别碰**（都是实测标定过的，改了机械臂会抓空或者把方块扫飞）：

| 参数 | 为什么不能动 |
| --- | --- |
| `GRASP_Z` / `PLACE_Z` | 抓握高度，实测标定的 |
| `SAFE_Z` / `MAX_JOINT_VEL` | 转运安全高度和关节限速，动了下场就是方块横飞 |
| `HOME_JOINTS` | 停靠位姿，精心挑过，机械臂不会挡住相机 |
| `IK_RESIDUAL` / `MOVE_TOL` | IK 求解精度，改成「看起来很小」的值反而会提前收敛跑偏 |
| `CAM_*` | 相机全部参数，动了视觉定位全乱 |

**改了 `config.py` 任何东西，群里说一声**，然后跑 `python smoke.py` 验一遍。
