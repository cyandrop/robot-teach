## 一、结论先说

之前给你的 `setup_env.bat` 有个前提没解决：**它第一步就要 `conda` 命令**，
你机器上如果没装 conda，第 1 行就报「不是内部或外部命令」，后面全废。

现在换成新的脚本 **`setup_env_无需预装conda.bat`**，它会：

1. 先自动找 conda（PATH → Miniforge/Miniconda/Anaconda 常见安装位置都找一遍）
2. **找不到就自动下载安装 Miniforge3**（清华镜像，约 150MB，静默安装，不改你的 PATH）
3. 创建 conda 环境 `robot` = Python 3.11 + pybullet + opencv + numpy（走清华镜像）
4. 自动验证依赖能不能 import
5. 自动跑 `smoke.py` 冒烟测试，直接给结论

## 二、你要做的三步（约 10 分钟，其中 8 分钟是等下载）

## 五、为什么必须走 conda，不能 pip

pybullet 在 PyPI 上**只有 Linux wheel**，Windows 上 `pip install pybullet` 会退化成源码编译，
需要 Visual Studio C++ 生成工具，基本装不上（我们实测过，全源失败）。
conda-forge 上有 Windows 预编译包，所以必须锁 **Python 3.11 + conda**。

## 六、出问题怎么反馈

别自己改代码。把**整段报错**复制发我（截图也行），并说明卡在第几步：

- 卡在 `[1/4] 没检测到 conda` → 大概率是下载失败（网络），重跑一次即可
- 卡在 `[2/4] 环境创建失败` → 网络中断（重跑，已下载的包不会重复下）或磁盘不足（需约 3GB）
- 卡在 `[3/4] 依赖导入失败` → 把报错发我
- `smoke.py` 里某个方块识别不到 → 先跑 `python tools\sample_colors.py`，别手改 `HSV_RANGES`
