## 三、你现在要做的四件事（按优先级）

### 1. 接 Qwen API（对应创新性/AI 应用，必做）

现在指令解析走的是关键词规则兜底（也能用，100% 准确），但报告里写「用了大模型」
必须有真实调用记录。步骤：

1. 去 [阿里云百炼](https://bailian.console.aliyun.com/) 注册，开通「通义千问」，拿 API Key
   （新用户有免费额度，够用）
2. Windows 设置环境变量：
   ```bat
   setx DASHSCOPE_API_KEY "sk-xxxxxxxx"
   ```
   设完**重开一个命令行窗口**才生效
3. 验证：
   ```bat
   python planner.py
   ```
   输出里 `source` 是 `llm` 就成功了；是 `rule` 说明没读到 Key。

**注意**：没 Key 或断网时会自动降级到规则解析，这是设计好的，不是 bug，
报告里可以写成「系统鲁棒性设计」。

### 2. 补充异常提示（对应项目实施，加分）

改 `robot_sim.py` 里 `execute()` 的分支，或者包一层返回结构，都行。

- 右下角显示当前指令的解析结果

**别动相机参数**（`CAM_EYE` / `CAM_FOV` / `CAM_W` / `CAM_H`）——
动了视觉定位会全乱，要动就群里说。

### 4. 加代码注释（最后两天）

## 四、哪些参数你能改，哪些不能碰

| 参数 | 位置 | 能不能改 |
|---|---|---|
| `HSV_RANGES` | config.py | ✅ 能改，改完跑 `python smoke.py` 验证 |
| `MIN_CONTOUR_AREA` | config.py | ✅ 能改，识别不到小色块时调小 |
| `API_MODEL` / `SYSTEM_PROMPT` | planner.py | ✅ 能改 |
| `CAM_*`（相机全部参数） | config.py | ⚠️ 别动，动了要重标定 |
| `GRASP_Z` / `PLACE_Z` / `SAFE_Z` | config.py | ❌ 别动，A 实测标定的 |
| `HOME_JOINTS` / `MAX_JOINT_VEL` | config.py | ❌ 别动，改了机械臂会撞飞方块 |
| `IK_RESIDUAL` / `MOVE_TOL` | config.py | ❌ 别动 |

**改完任何东西，先跑这条**：
```bat
python smoke.py
```
五关全过再提交。要是挂了，大概率是改了不该改的，回退就行。

## 五、排错工具（别自己瞎猜）

| 现象 | 跑这个 |
|---|---|
| 识别不到某个颜色 | `python tools/sample_colors.py` —— 它会直接采样目标在图像里的真实 HSV |
| 识别突然变差 | 多半是机械臂挡住相机了，先跑 `python main.py --cam` 看画面里手臂在哪 |
| 定位偏了 | `python evaluate.py --vision 20 --no-llm` 看具体误差多少毫米 |
