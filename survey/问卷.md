# 需求调研问卷（学生卷）

> **用法**：把题目复制到「腾讯问卷 / 问卷星」，发给本校机器人、自动化、人工智能相关专业的同学；
> 收够 **50 份以上** 就有说服力（评审看的是"你真的问过用户"，不是样本量本身）。
> 回收后导出 CSV 放到 `answers.csv`，跑 `python analyze.py` 自动生成图表和报告表格。

## 教师访谈提纲（另发，6 题，开放式）

1. 您目前讲授的课程与实验安排是怎样的？实验课占比多少？
2. 现有实验环节最大的困难是什么？（设备 / 课时 / 学生基础 / 安全 / 考核）
3. 一个零硬件、可在本机运行的仿真平台，您会在哪类教学场景中使用？
   （课堂演示 / 课后作业 / 课程设计 / 毕业设计 / 不会使用）
4. 您认为这类平台能否替代实体实验？如果不能，它应该处在什么位置？
5. 您希望平台提供哪些教学配套（教案、实验指导书、考核标准、数据集）？
6. 如果要在您任课的班级试点，您需要的支持是什么？

> 访谈 3-5 位老师即可，报告里引用原话比堆数据更有说服力。
