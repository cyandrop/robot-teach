# 需求调研工具包（模块 C 专用，对应「需求分析 15 分」+「应用效果 15 分」）

这两项目前是**完全空白**，也是最容易拿分的地方——因为不需要写代码，只需要真的去问用户。
工具包已经做好，队友要做的只有三步。

## 三步流程

```
第 1 步  发问卷    复制 问卷.md 里的题目到腾讯问卷，发到专业群/班级群，目标 50 份以上
第 2 步  导数据    问卷后台「导出 CSV」，改名为 answers.csv，放到本文件夹
第 3 步  出报告    python analyze.py     → 自动生成 report.html + 可粘贴的表格
```

## 先看效果（不用等数据）

```bat
python analyze.py --demo
```

会用 60 份模拟数据跑一遍，生成 `report_demo.html` 和一份 Markdown 表格，
**先确认产出是不是你要的样子**，再决定要不要改题目。

## 产出物

| 文件 | 用途 |
|---|---|
| `report.html` | 单文件可视化报告，双击打开，可直接截图放进方案文档 / PPT |
| 屏幕打印的表格 | Markdown 格式，**直接复制进方案文档的「需求分析」章节** |

图表是内联 SVG，不依赖 matplotlib（环境里没装），单文件可离线打开。

## 两个提醒

1. **多选题的分隔符**：脚本只认 `┋` `;` `；` `|`。选项名里自带的「、」「，」
   不会被当分隔符。如果导出的数据用了别的分隔符，改 `analyze.py` 顶部的
   `MULTI_SPLIT` 就行。
2. **别用模拟数据交报告**：`answers_demo.csv` 只是预览用的，
   评审如果看到"60 份完美分布"反而可疑。真实数据哪怕只有 30 份也比假的强。

## 教师访谈

`问卷.md` 末尾有 6 题教师访谈提纲，访谈 3-5 位老师即可。
**报告里引用一两句老师原话，比堆十张图表更有说服力**——
例如「我们实验室一台臂 30 万，一个班 40 个人，一学期每人上手不到 20 分钟」。

## 时间建议

| 日期 | 动作 |
|---|---|
| 10/2 | 发问卷（越早越好，收数据要时间） |
| 10/4 | 访谈 3-5 位老师 |
| 10/6 | 跑分析，把图表和结论写进报告 |
| 10/8 | 根据调研结论，回头在报告里说明"我们的功能就是针对这些痛点设计的" |
